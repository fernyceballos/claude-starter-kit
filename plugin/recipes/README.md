# Recipes

Recipes are bigger builds that go **inside a project you're building**, not skills for every
folder. Say the phrase in the right kind of folder and Claude takes it from there (it will ask
questions and show a plan first).

| Recipe | Say this | Where |
|---|---|---|
| Bug reports + bug digest (`bug-report-system.md`) | "add bug reports to my app" | a builder folder, once real people use the app |

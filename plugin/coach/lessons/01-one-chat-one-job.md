# One chat = one job

## What
Start a **new chat for each new job.** Finish one job, wrap it up, then open a fresh chat for
the next one.

## Why
A chat can only hold so much. When it gets full, Claude squeezes the older parts to make room.
Details get lost in the squeeze, and Claude starts to forget things you told it.

A new chat doesn't remember the old chat's words. But it isn't starting over: Claude reads this
project's notes (the files in its `docs` folder) at the start of every chat. "Wind down" (lesson 4)
is how the notes get written.

## Try it now
Look at the bottom of your screen. You'll see something like **"chat 3% full"**. That number
goes up as you talk. When it gets near 60%, type **continue in new session** (lesson 5 shows how).
Don't just open a new chat then, or the half-done work won't be in the notes yet.

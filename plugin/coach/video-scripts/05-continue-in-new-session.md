# Video 5 — "Continue in new session" (about 2 minutes)

**On screen:** the desktop app's right-side panel with **Context** at 62%.

Remember the Context number on the right side? When it gets to **60%**, this is what you do.
(In the Terminal version, the bottom of the screen tells you: "chat 60% full, say continue in
new session.")

Type **continue in new session.** It's for when the chat is filling up but the job isn't done yet.

Claude will save everything, even the half-done stuff. It writes down the decisions you made,
the things you already tried that didn't work, and exactly where it stopped. Then it gives you
a short message in a box.

*(Show the box.)* You copy that message, open a new chat, and paste it in. The new chat picks up
right where the old one left off, with a clean, empty chat to work in.

What's the difference from "wind down"? Wind down is for finished work. Continue in new session
is for work in the middle. Same idea: write everything down so nothing gets lost.

And if you ever see Claude say the chat "just got squeezed to make room," that's your sign you
waited a bit too long. No big deal. Say continue in new session right then.

So: 60% full means **continue in new session**, then copy, new chat, paste.

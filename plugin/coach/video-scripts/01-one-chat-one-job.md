# Video 1 — One chat = one job (about 2 minutes)

**On screen:** a Claude Code chat with the "chat N% full" meter at the bottom.

Hey, it's Ferny. This is the habit that matters most, so it comes first.

Most people use Claude like a normal AI chat. They open one chat and keep going in it for days.
That works for a while. But every chat has a limit on how much it can hold. When it fills up,
Claude squeezes the older parts of the conversation to make room. And in that squeeze, details
disappear: the decision you made yesterday, the thing you told it not to do.

So here's the rule: **one chat, one job.** You finish a job, you wrap it up, and you start a fresh
chat for the next one.

"But won't it forget everything?" No, and this is the part that makes it work. Your project
folder has a set of notes, the docs folder. Every new chat reads those notes first, so it knows
exactly where things stand. Starting a new chat isn't starting over. It's starting clean.

*(Point at the meter.)* See this at the bottom? "Chat 3% full." As you work, that number goes
up. When it gets to about 60%, it'll remind you to start a new chat. I'll show you exactly how
to do that in video 5.

That's it. One chat, one job. Next up: how to start a job the right way.

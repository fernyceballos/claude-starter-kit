# Video 8 — Growing: new folders for new kinds of work (about 2 minutes)

**On screen:** making a new folder, opening it in Claude Code, typing "start a project".

Last one. Let's talk about growing.

Each folder you set up is for one kind of work. **Operator** folders are where Claude works
inside your tools for you: your CRM, Slack, a website builder. **Researcher** folders are for
studying: break down a creator's strategy, watch their videos, find their frameworks.
**Builder** folders are for building an app or website with code.

Maybe you start with an operator folder. A month from now you want Claude to study a competitor's
Instagram. You don't need me, and you don't need any setup prompts. Make a new folder, open it in
Claude Code, and type **start a project.** It asks you one question and sets it up. Everything you
need is already installed.

Or if you want *this* folder to do more, say **upgrade this project.**

Why separate folders? Each one keeps its own notes, so the notes stay clear and focused.

That's the whole method: one chat per job, talk it through, wind down, continue in new session
when it's full, and say yes before anything goes live. If you get stuck, my contact is in your
setup. Now go build something.

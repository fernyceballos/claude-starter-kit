# SESSION LOG

Newest entry first. One entry per chat (or per big change in a long one). A future chat reads
the top 2–3 entries before doing anything, so write for someone with no memory of this chat.

## Entry format

```
## YYYY-MM-DD — <one-line headline>

**Status:** <done / in progress / blocked> — one sentence on the outcome.

### What was done
- Bullets, in order. Name the exact file, page, setting or URL touched.

### Verified how
- What was checked, where, and the result. If something was NOT checked, say so.

### Changed in live systems (with old values, for undo)
- System · setting · old value → new value. ("none" if nothing live changed.)

### Decisions made (details in DECISIONS.md)
- D-00X short name

### Left open
- What's not done, and what the next chat must check first.
```
